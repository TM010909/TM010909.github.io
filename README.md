# 永不完结

铜香哭哭死的个人站点：写生活、路上的事、代码和翻过的书。纯静态页面，不依赖框架，也不需要编译。

视觉走「密教抄本」：星盘刻度符印、月相、四角星芒、暗角与星尘、朱砂蜡封、罗马数字分章。深色主题是午夜墨黑 + 古金 + 紫水晶，浅色主题是旧羊皮纸 + 褪色墨 + 暗金压印；全部由 CSS 绘制，无外部图片依赖。

线上地址：https://TM010909.github.io

## 本地预览

直接用浏览器打开 `index.html` 即可；也可在目录下运行 `python -m http.server 8090` 后访问 `http://localhost:8090`。

## 如何添加文章

打开 `assets/posts.js`，在 `window.POSTS` 数组中复制一个文章对象，修改：

- `title`：标题
- `category`：生活 / 旅行 / 技术 / 随笔
- `date`：日期
- `read`：预计阅读时间，如 `约 4 分钟`
- `image`：封面图片地址，**可以留空**
- `excerpt`：列表摘要
- `body`：文章正文，用 `\n\n` 分段

正文支持两种轻量标记（不写就是普通文本，完全向后兼容）：

| 写法 | 效果 |
| --- | --- |
| `> 一句话` | 该段渲染为引用块 |
| `` `const x = 1` `` | 行内代码 |

保存并刷新网页即可看到新文章。

### 关于封面

`image` 留空时，页面会按分类自动绘制一幅会动的 SVG 微型场景插画（见 `assets/main.js` 的 `SCENES` 与 `style.css` 中的 `.cover-art-*`）：

| 分类 | 四元素 / 配色 | 场景 |
| --- | --- | --- |
| 生活 | 土 · 琥珀 | 窗台盆栽 |
| 旅行 | 水 · 靛青 | 山海与路 |
| 技术 | 气 · 紫水晶 | 终端窗口与闪烁光标 |
| 随笔 | 火 · 朱砂 | 信纸与钢笔 |

配色由 CSS 变量控制，深/浅主题自动适配。想换成自己的照片，把 `image` 填成图片地址即可，例如 `./assets/covers/trip.jpg`。填了地址就优先用照片，留空就用自动封面。全站不依赖任何外部图床。

## 功能说明

- 文章以弹窗形式阅读：底部有**循环的上／下一篇导航**（最后一篇的下一篇回到第一篇）、顶部阅读进度条、中文书刊式缩进与首字下沉
- 每篇文章有独立链接 `#post-N`：打开时地址栏自动更新，弹窗内可一键「复制本文链接」；直接访问带 hash 的地址会自动打开对应文章，刷新、收藏、浏览器前进／后退都会同步
- 分类筛选、关键词搜索、深／浅色主题切换（偏好保存在浏览器本地，刷新不闪烁）
- 顶部题词横幅、滚动入场、鼠标柔光、生长墨线、点击墨滴涟漪等动效，全部尊重系统「减少动态效果」
- 键盘：`Tab` 出现「跳到文章」跳转链接，`/` 聚焦搜索，`Enter`／`空格` 打开文章，`Esc` 关闭并把焦点还给原卡片
- 支持系统「高对比」偏好与打印（打印时收成一页干净的手稿）
- 所有逻辑都在浏览器端运行，没有后台、评论系统或数据库

字体来自 Google Fonts，需要联网加载；断网时会回退到系统字体，不影响阅读。

## SEO

`index.html` 内含 description、Open Graph、Twitter Card、canonical、theme-color 与 `application/ld+json` 结构化数据（WebSite / Blog / Person）。`og-image.png` 是 1200×630 的社交分享卡片，`robots.txt` 与 `sitemap.xml` 供搜索引擎收录。

## 文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面结构与文案、SEO 元信息、主题预置脚本 |
| `assets/style.css` | 主题配色、布局、SVG 场景与主视觉、打印样式 |
| `assets/posts.js` | 文章数据 |
| `assets/main.js` | 筛选、搜索、弹窗、文章导航、主题切换、动效 |
| `og-image.png` | 社交分享卡片（1200×630） |
| `robots.txt` / `sitemap.xml` | 搜索引擎收录 |

## 发布到 GitHub Pages

仓库已开启 Pages，把改动推送到 `main` 分支即会自动部署：

```bash
git add -A
git commit -m "更新文章"
git push origin main
```

首次配置：Settings → Pages → Build and deployment → Deploy from a branch → Branch 选 `main`，目录选 `/ (root)`。
